# [1.0.98](https://github.com/Cloudzero/provision-account/compare/1.0.97...1.0.98) (2026-05-26)

> Add `connectors_account_id` / `ConnectorsAccountId` to allow a second CloudZero AWS account to assume the cross-account role

## Features

### Second trust principal on the CloudZero role
A new optional parameter adds a second CloudZero AWS account as a trust principal on the customer's CloudZero IAM role. Backward compatible: existing customers re-deploying with no parameter changes pick up the default automatically; no impact on existing functionality.

- **Terraform** (`cloudzero-aws`, `cloudzero-payer`): new `connectors_account_id` variable. Default `931830253929`.
- **CloudFormation** (`master_payer.yaml`): new `ConnectorsAccountId` parameter. Default `931830253929`.

Override only if directed by CloudZero support.
