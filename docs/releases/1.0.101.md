# [1.0.101](https://github.com/Cloudzero/provision-account/compare/1.0.100...1.0.101) (2026-11-03)

> Add a manually triggered workflow that deploys a branch's artifacts to the dev S3 path for testing

## Features

### Deploy Branch to Dev workflow
* **New `Deploy Branch to Dev` workflow** (`workflow_dispatch`) - uploads the dispatched branch's templates, IAM policies, and Lambda zips to `s3://cz-provision-account/v1.0.dev/`, the same path `CD Dev` writes on every push to `develop` (CP-50879)
  - Takes 1-3 regions for the Lambda zips (`us-east-1`, `us-east-2`, `us-west-1`); defaults to `us-east-1`
  - Runs `make deploy version='dev'`, which never publishes to `latest/`
  - Uses the `dev` environment, so its deployment branch policy controls which branches may run it
  - Does not merge anything to `master`

Test a deployed branch by launching `https://cz-provision-account.s3.amazonaws.com/v1.0.dev/services/connected_account_dev.yaml`. `v1.0.dev/` is shared: the next `CD Dev` run or branch deploy overwrites it.
