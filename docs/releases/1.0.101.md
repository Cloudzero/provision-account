# [1.0.101](https://github.com/Cloudzero/provision-account/compare/1.0.100...1.0.101) (2026-11-03)

> Upgrade all Lambda functions from Python 3.12 to Python 3.14, and run CI on the same Python version as the deployed runtime

## Improvements

### Python Runtime
* **Upgrade from Python 3.12 → 3.14** for all Lambda functions (CP-50879)
  - `services/account_type/master_payer.yaml` - Inline CUR creation Lambda
  - `services/discovery/template.yaml` - Discovery service Lambda
  - `services/notification/template.yaml` - Notification service Lambda

### CI
* **Run lint and tests on Python 3.14** (previously 3.11.9) so CI exercises the deployed Lambda runtime
* **Raise `cfn-lint` floor to 1.59.0** - older versions do not recognize the `python3.14` runtime

## Files Modified
- `services/account_type/master_payer.yaml`
- `services/discovery/template.yaml`
- `services/notification/template.yaml`
- `.github/workflows/ci.yml`
- `requirements-dev.txt`

## Breaking Changes

**None** - No Lambda code changes required. Existing stacks pick up the new runtime when updated with `Version` set to `latest` (the default) or to this release. Stacks pinned to an older `Version` keep that release's runtime.
